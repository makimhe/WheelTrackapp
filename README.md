WheelTrack 

O WheelTrack é uma solução completa para o acompanhamento do processo de blindagem veicular. O foco deste repositório é a interface (Frontend) desenvolvida em React Native, projetada para oferecer uma experiência de usuário (UX) intuitiva e eficiente durante o monitoramento de veículos.
🚀 Sobre o Projeto

O sistema permite que o usuário acompanhe, em tempo real, as etapas de blindagem do seu veículo, garantindo transparência total e agilidade no acesso a informações técnicas.
🛠 Tecnologias Utilizadas

    Linguagem: JavaScript

    Framework: React Native

    Gerenciamento de Navegação: React Navigation (Tabs)

    Arquitetura: Componentização modular (Clean Architecture)

    Estilização: Design System centralizado (Colors & Fonts)

🏗 Arquitetura do Frontend

O projeto foi estruturado seguindo boas práticas de desenvolvimento:

    Modularização: Separação clara de componentes (/src/components) para garantir reutilização e escalabilidade.

    Separação de Serviços: Lógica de negócio isolada da camada de UI (arquivos de serviço para auth, vehicles e notifications).

    Mock Data: Camada de dados simulados implementada para testes de interface independentes do backend.
